镜序 · 本地短剧工作台

一、先安装运行环境
本包是源码便携版，需要 Node.js 22.9 或以上，不需要执行 npm install。
Node.js 官网：https://nodejs.org/
只有需要把多个视频片段合成整集时，才需要额外安装 FFmpeg（包含 ffmpeg、ffprobe），并加入系统 PATH。

二、启动
先完整解压到有写入权限的普通文件夹，不要直接在压缩包里运行。
Windows：双击“启动工作台.bat”。
macOS：双击“启动工作台.command”。
也可以先双击“创建桌面快捷方式”（macOS 为 .command，Windows 为 .bat），以后直接双击桌面的“镜序工作台”启动。
如果系统不允许双击，在终端进入解压目录，执行 npm start。
浏览器访问：http://127.0.0.1:6040/
后台窗口运行期间请保留；关闭窗口会停止后台服务。

三、配置自己的接口
点击左下角“接口设置”，填写自己的三家 API Key：
文本：DeepSeek，预设 deepseek-flash。
图片：Grsai 中转站，预设 gpt-image-2.6。
视频：菲阳动漫，预设 c7-wan3，15–30秒，720p/1080p。
本包不带任何人的 Key、已有剧本、图片或视频。
图片和视频调用按服务商规则计费。视频服务标记模型未上架时会阻止提交。

四、制作
新建项目并粘贴完整剧本 → 拆解剧本并列资产清单 → 修改、勾选资产 → 生成所选或全部图片 → 页面最底部列出全部分镜 → 修改、勾选并确认生成视频。
五类系统提示词在“接口设置 → 系统提示词”里配置，留空使用默认规则。
人物图默认为单张16:9面部特写加三视图。
“跳过人工检查”默认关闭。打开仅保存模式，点击开始后才自动衔接图片、分镜和视频；此模式会消耗接口额度。

五、保存与迁移
资料保存在解压目录的 data/projects/，只属于当前电脑。接口配置保存在 .env。
迁移项目时先关闭后台，再复制 data/projects/；对方使用自己的 Key，无需复制 .env。
不能跨电脑直接打开别人的 localhost 地址，每台电脑各自启动。
详细说明见 docs/使用说明.md。

已在 macOS 验证运行；Windows 提供启动入口，尚未做 Windows 实机验证。
