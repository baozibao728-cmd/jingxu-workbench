# 镜序 · 本地短剧工作台

在浏览器中输入剧本，先列出人物、场景和道具清单，由你勾选后生成图片，再逐段生成并完整列出可编辑的分镜提示词。**默认在资产清单和视频分镜两处等待你确认；也可开启“跳过人工检查”，点击开始后自动衔接生成。**

渠道：DeepSeek V4.1 Flash → Grsai 中转站 GPT Image 系列 → 菲阳动漫 c7-wan3。

## 启动

需要 Node.js **22.9 或以上**，无第三方 npm 依赖。

- macOS：双击 `启动工作台.command`。
- Windows：双击 `启动工作台.bat`。
- 想放到桌面：双击 `创建桌面快捷方式.command`（macOS）或 `创建桌面快捷方式.bat`（Windows），以后双击桌面的“镜序工作台”即可启动。
- 或在此目录执行 `npm start`。

浏览器地址为 `http://127.0.0.1:6040`。后台窗口需要保持打开。重复启动会复用已有实例。

首次在新电脑使用时，点击左下角“接口设置”配置厂商方案。已有 `.env` 继续读取；界面保存的方案位于本机 `data/projects/provider-settings.json`，Key不会回显，更新时保留。生图默认仍使用 Grsai 中转站原生接口。

视频合成需要安装 FFmpeg（包含 `ffmpeg` 和 `ffprobe`）；单个分镜的生成、播放和下载不依赖 FFmpeg。

## 制作流程

1. 新建项目，粘贴剧本，选择风格、比例并补充规则。
2. 点击“拆解剧本并列资产清单”：按场景分段，只分析并列清单，不生图。
3. 勾选需要的资产，点击“生成所选”或“一键全部生成”。完成后逐段生成分镜提示词；已有图片直接复用。
4. 在资产卡片中编辑描述和提示词、单独重做图片，或上传图片替换。
5. 在页面下方编辑分镜。在提示词输入 `@` 后从候选列表选择素材，自动绑定实际图片；缩略图点击只放大预览。
6. 选择分镜，打开确认弹窗，检查完整提示词和参考图，点击“开始生成视频”。
7. 视频在后台排队、生成并自动下载。页面支持刷新和切换项目，结果可播放和下载。
8. 所有分镜的当前视频完成后，可点击“合成整集”。原始片段保留。

当前视频模型为 `c7-wan3`，支持 **15–30秒、720p/1080p**，新项目默认15秒、720p。旧5秒分镜不会自动改时长，请在分镜编辑器中同步修改时长与提示词，再审阅确认。提交前会刷新服务端能力；模型未上架时会拦截提交。本模型尚未做真实视频生成测试。

人物图每次只生成一张16:9横版设定图：左侧面部特写，右侧正面、90°侧面、背面三视图。固定前置提示词位于 `prompts/character-sheet-system.txt`，新建和重做人物图片时都会自动加入。

## 系统提示词与长剧本

顶部“并发设置”可分别调整资产图片和视频并发，默认各10条，范围1～50；滑块、数字输入和快捷预设均可使用，设置保存在本机并作用于所有项目。调高立即填充空位，调低等待在途任务完成后按新上限排队。实际速度仍取决于服务商额度。

生成的图片支持透明背景放大、拖动查看、直接滚轮缩放和适应窗口；点击旁边空白或Esc关闭。接口设置的图片模型下拉新增“Image2 · GPT Image 2”，对应中转站 `gpt-image-2`，保留原有默认模型。

左下角设置 → 系统提示词，可分别配置分镜拆解、角色提取、场景提取、道具提取、分镜输出格式要求。留空用默认值，可单项恢复默认；固定JSON字段和素材引用格式保持兼容。

单份剧本支持10万字以内，按场景及长段落分块，保留全部原文；不再限制整剧24项资产或40条分镜。每段分析、分镜完成后保存，失败可续接。全部分镜列完前不能提交视频。

每条分镜旁都能直接修改时长，编辑器里也可改。新增“重新拆分分镜”，用DeepSeek只重新处理当前条，可拆成多条；先设目标时长再点击AI重拆，原记录和已有成片保留，完成后仍需确认视频。

## 保存与恢复

项目的“剧本与制作设置”新增“跳过人工检查”，默认关闭。开启只保存模式，不立即生成；点击“开始全自动生成”才会依次分析清单、生成选中资产、列出全部分镜并自动提交视频，按供应商规则计费。关闭会停止后续自动衔接和未提交的视频，已提交任务继续查询。后台重启不自行启动新一轮完整生成。已有成品直接复用，模型参数、引用和未知提交保护仍然有效。

项目数据和素材保存在 `data/projects/`；原始接口联调结果保存在 `data/integration-test/`。刷新网页不会停止后台任务。

关机前先确认视频已经拿到服务端任务编号；仍在本机排队的任务需要后台在线提交。重新开机后必须启动工作台，已有编号的未完成/下载失败视频会自动查询并下载，不会重新提交生成。服务商原文档注明视频链接有效24小时，请及时接收；服务端留存以供应商为准。

后台重启后，已有视频任务会继续查询；图片任务可通过“生成所选”或卡片上的查询按钮恢复。提交结果未知时标记“待核对”，不会自动重复提交。

修改图片或分镜后，旧确认会失效。修改已制作的整篇剧本或整体规则后，再次拆解会另建项目版本，原素材和视频保留。

## 换电脑

复制便携包，安装 Node.js 后启动。在新电脑的接口设置中填写 Key。

继续现有项目时，另行复制 `data/projects/`（含自定义系统提示词）。便携包不包含 `.env`、现有项目、生成素材或视频。

## 验证

`npm test` 使用模拟服务，不消耗生成额度。`npm run check` 只显示配置状态，不输出 Key。

已完成三家真实接口联调、经用户确认的一条5秒视频，以及工作台“输入剧本→资产图片→分镜就绪”的真实流程。生成模型可能偏离美术要求，请在确认前查看实际图片并按需重做或替换。

macOS 上完成本地浏览器和媒体播放检查。Windows 启动入口已提供，尚未进行 Windows 实机验证。

详细操作见 [使用说明](docs/使用说明.md)。

## 1.1.0 厂商、更新与分镜衔接

设置→接口配置，可为文字、图片和视频分别新增、保存、切换厂商方案，模型ID可自由填写。同一方案Key留空保留，新方案不会串用另一方案的Key。支持的协议、字段和限制见[公开发布与自动更新](docs/公开发布与自动更新.md)。

设置→软件更新，仓库地址稍后填写。填好公开GitHub发布仓库后可自动检查、空闲安装并重启。只更新程序；Key、data、项目、素材与历史保留，旧程序先备份。当前没有上传GitHub。

重拆前面的分镜后，后续条目显示“待对齐衔接”。可点“一键AI对齐后续”，或逐条检查后点“已核对，确认衔接”；完成前拦截相应视频提交。AI结果仍需查看，不能保证画面语义绝对连续。旧分镜和成片保留。
