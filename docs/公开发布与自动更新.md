# 公开发布与自动更新

版本1.1.0起支持从公开GitHub仓库的Release获取更新，当前版本1.5.9。默认发布仓库为 baozibao728-cmd/jingxu-workbench，公开源码与更新包不含Key和用户数据。

## 使用者

进入左下角“接口设置”→“软件更新”，填写发布者提供的“账号/仓库名”。默认开启自动检查和空闲自动安装：启动3秒后检查，运行期间每3分钟检查；有任务时等待，空闲后重试。也可关闭自动安装，自己点“立即检查”与“安装新版本”。目前公开仓库可用，私有仓库访问认证尚未接入。

安装前校验路径、版本号和每个文件的SHA-256；旧程序备份在 `data/program-backups/`。只替换程序文件，绝不删除或覆盖 `.env`、整个 `data/`、用户剧本、图片、视频、历史、自定义系统提示词、并发和厂商配置。中途写入失败会回滚已写入的程序。已有任务结束后再更新，更新成功后服务自动重启，页面重新连接。

目前本地模拟测试通过；仓库发布后，仍需验证第一次真实GitHub下载更新。发布仓库的维护者能够发布新程序，请填写自己信任的仓库。

## 厂商配置

文字、图片和视频分别选择已保存的厂商方案，也可新增。Key框不回显；编辑同一方案时留空保留，新方案不自动借用另一方案的Key。原 `.env` 不改写，新方案保存到 `data/projects/provider-settings.json`（权限600），更新时保留。配置更改保留连接历史，已提交任务继续使用原厂商连接查询。

支持DeepSeek/OpenAI Chat Completions、Grsai原生、OpenAI Images纯生图、菲阳原生，以及HTTP JSON自定义适配。需要填写：方案名、协议、HTTPS基础地址、模型ID、Key、认证头及前缀、超时；兼容协议可填提交路径。自定义JSON还需按供应商文档填写提交/查询/上传路径，请求模板、响应字段和状态映射、参考图上传方式与引用标记。视频需声明时长、分辨率和参考图限制。供应商需支持这些协议或完成对应适配；动态签名等专有原生协议不能仅改地址就通用。

视频厂商预设还包含“萤漫 OpenAI兼容视频”。它使用 `https://yingman.xlapis.com/v1/videos`，模型 ID 为 `seedance-2.5-cc` 和 `seedance-2.5-flash-cc`。参考图通过 `input_reference`、参考音频通过 `input_audio` 随 multipart 请求上传，任务完成后从 `/v1/videos/{id}/content` 下载。该适配需要萤漫“设置 → API 密钥”创建的站内 Key，Key 只保存在本机方案配置。

视频厂商预设还包含“惠喵 Huimiao”（`https://huimiaovip.com`，Key 以 `hm_live_` 开头，在网页工作台“API调用”里创建；分站用户改成自己分站的域名）。按惠喵原生接口：参考图和参考音频直传到惠喵自己的存储（申请地址 → 上传 → 确认），提交带幂等键，下载跟随跳转且不把 Key 带到别的域名。预设列出文档中的 7 个公开模型及其时长、参考数量；清晰度在“视频参数”里填，点“测试”会报出所选模型实际支持的清晰度、时长和积分余额。

文本厂商预设还包含“悟空 API（wkapi）”：OpenAI Chat Completions 兼容，地址 `https://wkapi.work`，提交路径 `/v1/chat/completions`，预设 Gemini 3.8 Flash / 3.1 Pro / 4 Argon 和 Claude Sonnet 4.6。Key 的分组要和模型对应（Gemini 用 Gemini / Gemini-Pro 分组，Claude 用 Claude 分组），分组不匹配会报 401 或模型不存在。

视频厂商预设还包含“Scenetra”（`https://app.scenetra.com`，Key 以 `scnk_` 开头，在它网站的 API 页面创建）。可选 Seedance 2.5 / 2.5 Flash / 2 / 2 Fast / 2 Mini、Kling 4.0、Wan 3.0 / 3.0 Prime、MiniMax H3、Happy Horse 1.1、Grok Imagine Video 1.5、PixVerse v6、Gemini Omni 1.2 Flash；时长、清晰度、参考图数量按模型自动确定（Seedance 2.5 每条最多 30 张参考图）。有参考图走参考生视频，没有就走文生视频；每次先用 `?dryRun=1` 免费校验参数和价格，再正式提交。Scenetra 的参考素材只收公网 https 地址，所以参考图和参考音频会先传到临时图床（uguu.se，3 小时后删除；连不上时用 tmpfiles.org，1 小时后删除），有地址的人在这段时间内可以打开；m4a 音频先转成 mp3。

OpenAI Images兼容模式目前只接纯生图；尺寸默认横版1536×1024、竖版1024×1536，实际尺寸以供应商为准，可自行设置。用户原Grsai协议仍支持原来的比例与参考图参数。带参考图编辑或其他协议请按供应商规范另配JSON适配。

## 发布者

先把 `outputs/镜序工作台_GitHub源码包.zip` 解压后的内容放入公开仓库。这个源码包按白名单打包，不带 `.env`、`data/`、旧共享Key包、用户资产清单或真实联调记录。不要直接把整个工作目录上传。

发布步骤：

1. 修改 `package.json` 的版本号，例如 `1.1.2`。
2. 运行 `npm test`，再运行 `node scripts/build-update.mjs`，产出不含用户数据的 `outputs/jingxu-update.json`。
3. 在GitHub创建对应标签 `v1.1.2` 的Release，并附上该JSON；只推送源码而没有Release不构成更新。
4. 源码包附带 `.github/workflows/release.yml`，启用Actions后推送匹配版本的 `v*` 标签，可自动测试、构建并发布。流程只使用GitHub自动提供的发布令牌，不需要生成模型的Key。
5. 告知使用者“账号/仓库名”，让每台电脑保存一次。以后发布新版本即可自动检查。

`jingxu-update.json` 包含程序文件的base64与摘要，属于可发布程序包。可在Windows/macOS安装；Node仍需22.9以上。更新不执行用户数据迁移删除操作；今后若修改数据格式，应继续保留旧字段和文件。


## 1.1.1 模型列表与整剧重解析

“一键AI对齐后续”已移除，原位置统一使用“全部重新解析分镜”。整剧按原文顺序分段重新生成提示词，复用资产图；全部成功才替换，旧分镜与成片保留，失败可继续。仅调用文字模型，不自动生成图片或视频。单条编辑与人工确认衔接仍可用。

设置→接口配置：文字、图片、视频的每个厂商方案均可保存多个模型。每行填写模型ID，可加“| 显示名称”，再在“当前使用模型”下拉框选择并保存。图片默认恢复原六个预设（Image2、2.6、VIP、2.5、Flare、Sunburst），也可添加自定义型号。预设名称不代表厂商当前一定开放，实际支持以供应商为准。资产区标题旁可直接切换生图模型，切换不触发生成；有任务时需等待完成后切换。已有Key与记录保持原样。

## 1.3.0 界面改版与导出导入

- 界面：白天、夜间、跟随系统三种主题；毛玻璃面板与动态背景，左下角可开“静态背景”；去掉顶栏，侧栏可收起成图标栏；新的图形标志。
- 剧本库：点“选择”后整张卡片可选；可把剧本连同资产图、视频导出成一个 ZIP，也可导入这样的 ZIP。包内不含 Key 和厂商配置。
- 分镜解析：输出被截断时自动拆段继续，返回为空或引用写错时自动重试；全部重新解析后不再要求重新拆解资产。
- 接口设置：厂商方案可一键测试连接（生图、视频只查询不生成）；厂商图标；文本预设新增 Gemini、Claude、GPT。

## 1.3.1 拖图替换资产

- 人物、场景、道具三种资产卡片都可以把图片直接拖上去替换，不用再从文件夹里选。

## 1.3.2 导入、视频渠道与系统提示词

- 系统提示词不再内置：分镜拆解、角色/场景/道具提取、分镜输出格式五项默认为空，需要在“接口设置 → 系统提示词”里自己填写。更新前没有填过的电脑，更新后这五项是空的。
- 剧本库：把导出的 ZIP，或 TXT / Markdown 剧本拖进窗口即可导入；“导入剧本”按钮仍可点击选文件。
- 视频渠道：一个厂商方案的每个模型都能在项目里单独选。萤漫方案点“测试”会显示积分余额，下载成片支持跳转。
- 修复：删除剧本后确认窗口关不掉；点“启用”后跳回第一个标签；萤漫被显示成 GPT 图标。

## 1.3.3 清理旧版内置提示词

- 启动时自动删除旧版本留下的内置提示词文件（程序目录里的分镜格式模板，以及更新备份里带旧规则的程序文件）。使用者自己保存的提示词、项目和素材不受影响。

## 1.4.0 自由创作

- 侧栏新增“自由创作”：不用拆剧本和分镜，写一段提示词，直接生成视频或图片。
- 参考图可以点选、拖入或粘贴；输入 @ 引用某一张图，引用显示成带缩略图的小标签，悬停可预览，点击看大图。
- 模型、画幅、分辨率、时长在输入框下方选择；视频用“接口设置”里已配置的视频方案，图片用当前启用的生图方案。
- 生成记录和文件保存在本机 `data/projects/_studio/`，更新时保留。失败的任务可以“继续查询”，不会重复提交。
- “画布”入口已预留，功能尚未开放。

## 1.5.0 画布

- 自由创作的“画布”开放：可以平移、缩放、框选，把图片节点连线到生成节点作为参考，连线上有流动的光；节点可以成组。
- 连线的小圆点悬空在节点旁，鼠标靠近会被吸过去；拖线时松手会保留连线并弹出菜单；拖到窗口边缘时画布自动跟着走。
- 画布支持上传音频和视频。图片节点可预览、下载；视频节点可预览、下载、分离音视频；音频节点可下载、截取片段，红色播放线可以拖动定位。
- 音频节点可以连到视频生成节点作为参考音频（每个最多 3 段），提示词里用 @音频N 引用。需要所选视频厂商支持参考音频。
- 提示词输入框右上角可以展开放大。
- 分离音视频和截取音频需要电脑上装有 FFmpeg（含 ffprobe），处理结果保存在本机，原文件不改动。
- 接口设置：点“选择”可以选中已添加的厂商方案并删除；正在使用的方案不能删，删除只是隐藏，原有记录和 Key 保留在本机。
- 背景更清晰：修复动态背景分辨率被自动降低导致发糊的问题，夜间模式背景更亮。
- 自由创作标题换成 “Create anything you imagine”，进入和切换时 anything 有一道流光。

## 1.5.1 自动安装 FFmpeg

- 电脑上没有 FFmpeg 时，工作台启动后会在后台自动下载安装，不用自己装。整集合成、分离音视频、截取音频都会用到它。
- 从 GitHub 下载对应系统的版本（ffmpeg-static b6.1.1），核对大小和 SHA-256 后放在 `data/tools/ffmpeg/`，以后更新会保留，只装一次。Mac 约 38MB，Windows 约 59MB。
- 网络连不上 GitHub 时会提示安装失败，下次用到时自动重试。电脑上已经装了 FFmpeg 的直接用原来的。

## 1.5.2 新视频渠道、重新解析修复

- 新增视频渠道 Scenetra：在接口设置里选“Scenetra”预设，填 Key 即可。参考图和参考音频会先传到公开临时图床（uguu.se，备用 tmpfiles.org），1～3 小时后自动失效；提交前先做一次免费校验，校验连不上时不会提交、不扣积分。
- 新增视频渠道惠喵（huimiaovip.com）：参考素材走惠喵自己的直传，提交带幂等键，不会重复扣费；连接测试会报出模型实际支持的清晰度和可用积分。
- 文字服务新增悟空 API（wkapi）预设，可用于剧本拆分。
- 修复“全部重新解析分镜”在慢模型或中转站上中断：文字调用至少等 10 分钟，超时的长段落自动拆小再解析；失败时显示真实原因，不再统一显示“提交结果暂不明确”。
- 拖线时画布边缘跟随变慢、更平稳；连线流光改为细而清晰的蓝光。

## 1.5.3 解析与下载更稳

- 修复“全部重新解析分镜”报“文字服务返回的JSON不完整”就中断：模型把 JSON 包在代码块里时照样能读；只写了半个 JSON 时，这一段自动拆小再解析；其他读不出的回复会自动再试，失败时说明收到了多少字。
- 中断日志不再出现重复句号“。。”。
- 视频、图片已提交后查询进度时，遇到网络断开、服务端 5xx 或 429 限流会自动重试，不再直接判为失败。
- 成片下载改为写入磁盘，一段时间没有数据才算超时（不再按固定总时长），失败最多自动重试 3 次，并用中文说明原因。

## 1.5.4 分镜与生图并发、资产分类与多张抽卡

- 拆解剧本后同步列出资产清单与分镜清单（不含提示词），不再等待资产图生成完成才出分镜；资产生图与分镜提示词生成可同时进行。
- 分镜区新增“选择”模式按钮与“生成所选提示词 / 补齐待写提示词”按钮，可勾选由 AI 生成的分镜，也可手动填写提示词（资产图未完成时也可输入 `@` 引用素材，并支持根据提示词中的时间戳自动识别和切换分镜秒数）。
- 资产区默认按“人物、道具、场景”三类分组展示，各分类支持一键全选，编辑弹窗支持修改所属分类。
- 资产卡片新增“多张抽卡”（重新生成多张），可一次性并发提交 2～10 张图片生成任务，生成的候选图保留在卡片与编辑弹窗中，点击即可切换当前使用的资产图。
- 系统提示词单栏字数上限提升至 20 万字並显示实时字数，补充制作规则与重解析要求提升至 10 万字，粘贴长规则不再被截断。

## 1.5.5 多穿搭参考基础图生图与六模块系统提示词一键导入

- 角色多穿搭及场景/道具变体生图支持参考图锁定：拆解或按规范命名时自动绑定同角色第一张基础设定图（也可在资产编辑弹窗手动指定/改绑「参考已有资产图」）；批量生图改为分波次生成，先出第一张基础图，再自动将其作为参考图继续生成后续穿搭、重做及多张抽卡，保持脸型五官与结构一致。
- 「接口设置 → 系统提示词」升级为「公共约定（总纲）+ 模块一～六（场景、角色、道具、商品、角色追加形象、分镜拆解）+ 分镜输出格式覆盖」，无需重复粘贴公共约定六遍。
- 系统提示词面板支持多选或直接拖入 `.txt` 模块文件与 `.json` 配置包一键导入并保存，同时支持一键「导出配置包」，方便团队成员自行加载最新提示词模板。

## 1.5.6 去除冗余画风设置、加快后台检查更新

- 删除剧本制作设置中不再使用的「画面风格」下拉选项，生图与分镜不再强制注入「写实电影」或其它固定画风后缀，全部遵循系统提示词（如六模块《公共约定》的真实摄影/生活纪实要求）。
- 后台自动检查更新的轮询间隔从每 30 分钟缩短为每 3 分钟检查一次（启动 3 秒后首次检查不变），在保证不触发 GitHub 接口限流的前提下更快收到新版本推送。

## 1.5.7 解锁“待核对”分镜死锁与错误提示修复

- 修复分镜卡片在触发「待核对（`unknown`）」后既无法重新生成视频、又无法「重新生成提示词」、界面上也没有解锁或继续查询入口的死锁问题：
  - 卡片右下角对已有 `taskId` 的「待核对」任务开放 **「继续查询」** 按钮；
  - 对无 `taskId` 或需要重跑的「待核对」任务新增 **「已核对，解锁重试」** 按钮，弹窗提示先到厂商后台确认无重复扣费后即可一键清除待核对锁，恢复重生成提示词或视频提交。
- 修复分镜已执行过「重新生成提示词」后，状态栏一直只显示“当前分镜提示词已更新”而掩盖掉真实视频报错或待核对原因的显示问题。

## 1.5.8 萤漫支持 480p 与即时切换渠道参数

- 萤漫 OpenAI 兼容视频渠道（Seedance 2.5 / 2.5 Flash）新增 `480p` 分辨率选项（含竖屏 `480x854`、横屏 `854x480`、方形 `480x480` 及 `720p` 竖屏 `720x1280` 等尺寸自动匹配），并自动兼容此前已保存的萤漫配置使其立即出现 `480p / 720p`。
- 在剧本制作设置中切换「视频渠道」下拉框时，「每段时长」与「视频分辨率」下拉选项立即按新渠道参数刷新，无需等到保存修改后才看到新渠道可选的分辨率（解决此前从 720p/1080p 渠道切到萤漫时暂时还显示旧选项的问题）。

## 1.5.9 语音接口统一进接口设置、剧本与设置即时自动保存

- 「接口设置 → 接口配置」新增 **「语音合成」** 分类并内置 **MiniMax 语音合成** 预设（默认地址 `https://api.minimax.cn`，模型列表包含 Speech 2.8 / 2.6 / 02 等 6 个预设型号，支持连接测试）；「语音工作台」去掉单独填 Key 栏，直接共用「接口设置」里的 Key，并提供「去接口设置填 Key」快捷入口。
- 去掉「剧本与制作设置」右上角多余的「保存修改」按钮，改为 **即时/自动保存**（状态显示 `已自动保存`）：开关与下拉选项切换后立刻保存并刷新界面；剧本与补充规则文本在停止输入（含中文输入法上屏）或失焦后自动保存，不再需要每次改动后去点一次保存按钮。
