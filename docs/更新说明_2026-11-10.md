# 镜序工作台更新包

供已经安装过的电脑覆盖更新。保留旧 `.env` 和整个 `data/`，只合并更新程序文件；压缩包内没有Key或用户项目。不需要重新填写Key或执行 `npm install`。

本次包含：

- 图片、视频各默认10条并发，可独立调1～50。
- 全选不再整屏闪动，图片透明放大，直接滚轮缩放、拖动和空白关闭。
- 输入 `@` 选择素材，缩略图只预览；单条分镜可改时长和AI重新拆分。
- 完整详细分镜模板，时长和横竖屏跟随设置，自动生成每段最多9张参考图。
- 有编号的未完成视频重启后继续查询和下载，保留旧任务避免重复提交。

已完成的分镜不会自动重写；已有自定义系统提示词也不会自动覆盖。需要采用详细默认模板时，可在设置里查看默认内容后自行恢复默认。

安装操作见压缩包根目录的 `豆包更新指令.txt`。所有检查只验证界面和本地状态，不应提交真实生成任务。
