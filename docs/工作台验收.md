# 本地工作台验收记录

## 已实现

- 剧本、风格、画面比例和补充规则输入，项目保存与切换。
- DeepSeek 提取资产 → Grsai 生图 → DeepSeek 分镜，准备完成后停止等待确认。
- 资产描述/生图提示词编辑、单张重做、手动替换图片。
- 分镜编辑、点击插入素材引用、完整提交内容与素材预览。
- 只有确认按钮可以提交视频，确认绑定具体提示词与图片版本，处理中重复点击被拦截。
- 后台持久化任务、进度查询、刷新恢复、成片播放和下载。
- 本地整集合成，合成失败不回退为第一段并冒称成功。
- 本地 Key 配置，界面/API 不回显 Key；跨电脑启动入口与不含 Key 的便携包。

## 初版验证结果（历史记录）

1. 最终25项自动检查通过，覆盖三家接口协议、自动准备顺序、确认失效、重复提交、后台恢复、未知提交结果处理、合成失败、配置保存和HTTP媒体读取。
2. 从真实界面创建项目并输入单镜头剧本，真实完成三项资产提取、图片下载及一条5秒分镜，最终状态为“等待你确认分镜”。本轮没有新增视频生成任务。
3. 初次实际看图发现人物/场景图混入剧情元素，已移除直接附加到生图输入的整段项目备注，并加入独立资产类型的构图约束。仅重做这两项后，已实际查看：人物为纯背景全身图、书房为无人空景。道具图保留，不重复生成。
4. 浏览器验证素材编辑保存跨刷新保留、分镜编辑跨刷新保留、图片替换、三张参考图和完整提示词的生成前确认。
5. 已生成的真实5.088秒成片可在界面播放。单段整集合成通过界面触发并播放；两段媒体拼接另做了本地实际FFmpeg验证，总时长约10.10秒。
6. 1440px桌面和390px小屏检查无横向溢出，素材实际加载。修复了底部操作条遮挡分镜卡片的问题。

## 交互修正：选择、透明预览、@候选、时长与AI重拆

- 全选和单选只更新复选框、计数与操作栏，不重建图片或工作区，不触发整屏视图过渡。浏览器验证两次资产全选后图片DOM和工作区DOM未变、整屏过渡调用0次；46条分镜全选亦未重建图片。
- 图片预览周围完全透明，底层页面可见；直接无修饰键滚轮从100%缩放至175%，页面缩放仍为1；点击旁边空白关闭。编辑器下方缩略图改为仅预览，点击前后提示词一致。
- 输入@弹出可用素材候选，支持名称筛选、鼠标点击和方向键/Enter选择。分别插入书房和主角引用；Esc隐藏候选并保留编辑器，关闭编辑器无残留候选DOM。
- 每条分镜卡片直接显示时长下拉，编辑器内仍有时长选择；15→30秒跨刷新保留。新增AI重新拆分入口，可补充要求并拆成多条，只替换当前条；失败保留原条、原图及已有视频不丢失，也不自动提交视频。原分镜保存在项目的storyboardHistory。
- 模拟AI通过页面将45条中的一条拆成两条，共46条，其他条保留；重拆时长30秒。新增测试覆盖非法引用失败、等待时阻止编辑/生成、时长变化令旧确认失效。
- 有远端编号但查询/下载失败的视频，重启会继续查询和下载；本机未提交项不自动重提，未知提交仍等待核对。新增隔天恢复测试只有GET查询原任务并下载，没有POST生成。
- 完整44项模拟检查通过；追加原任务保护后相关17项检查通过。390px下@候选和透明预览无横向溢出。截图：outputs/透明图片预览.png、outputs/素材引用候选.png。
- 没有调用真实文本、生图或视频生成接口。本次测试不能证明供应商永久保存成片；按原文档视频链接有效24小时，应及时启动接收。
