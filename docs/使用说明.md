# 镜序工作台使用说明

## 第一次使用

安装 Node.js 22.9 或以上，macOS 双击 `启动工作台.command`，Windows 双击 `启动工作台.bat`。也可以在项目目录运行 `npm start`，随后打开 `http://127.0.0.1:6040`。

要创建桌面一键启动：macOS 双击 `创建桌面快捷方式.command`，Windows 双击 `创建桌面快捷方式.bat`。创建后直接双击桌面的“镜序工作台”即可；移动整个目录后重新运行创建脚本即可更新。

新电脑在左下角“接口设置”分别填写 Key：

| 用途 | 地址 | 模型 |
|---|---|---|
| 剧本与分镜 | `https://api.deepseek.com` | `deepseek-flash`，对应 V4.1 Flash |
| 图片 | `https://grsaiapi.com` 或 `https://grsai.dakka.com.cn` | 默认 `gpt-image-2.6` |
| 视频 | `https://fydmai.com` | 当前 `c7-wan3` |

Key 输入框不会回显，留空保存会保留已有配置。

## 输入剧本并准备资产

新建项目后粘贴剧本，选择风格和画面比例，可填入额外规则。点击“拆解剧本并列资产清单”后，只分析文字并列出全部资产清单，不会生成图片。先修改或勾选资产，再点“生成所选”或“一键全部生成”。图片默认最多并行10项，已有图片复用；完成后逐段生成分镜，全部列在页面最后。默认只有你审阅并点击确认，才会提交视频。

人物每项固定生成一张16:9横版设定图：最左约30%为面部细节特写，右侧约70%从左到右为正面、严格90°侧面（朝画面右侧）、背面全身。全部视图为同一人、同一服装，三视图头脚对齐，不拆开调用。固定前置规则保存在 `prompts/character-sheet-system.txt`，每次人物新生图或重做时自动加载；在人物编辑窗口也可展开查看。人物图的比例不跟随视频比例变化。

场景图要求空景；道具图要求单件、白底、无手。生成模型可能偏离要求，确认前要查看实际图片，可单独重做或上传自己的图片替换。

一份剧本支持10万字以内，按场景和长段落分块，原文完整保留；整剧不再受24项资产、40条分镜的限制。分段完成后逐次保存，失败可续接。未完成全部分镜时会阻止视频提交。当前视频支持15–30秒、720p/1080p，新项目默认15秒和720p；制作设置中可以修改。旧5秒分镜保持原样，需要在“编辑提示词”中修改本镜时长，并同步调整时间线，审阅确认后再提交。服务端标记未上架时会拦截视频提交；不会自动改用其他模型。

## 配置系统提示词

左下角“接口设置”打开工作台设置，切换到“系统提示词”。五项分别是分镜拆解、角色提取、场景提取、道具提取、分镜输出格式要求。文本框留空即使用内置默认值，可展开查看默认文本；“恢复默认”清空该项，再点击“保存系统提示词”落盘。

自定义规则影响后续分析，已列出的内容不会自动重做。一次长剧本分析使用同一份规则快照，失败续接保持一致。JSON字段和素材引用约束保留，避免格式失效。自定义规则保存在 `data/projects/system-prompts.json`，随项目目录可一起迁移。

“分镜输出格式要求”已内置详细短剧模板：时长、上传顺序、人物声音、场景机位、物品尺度、Style、Color、逐镜画面与声音、禁止项。留空即使用这套默认模板，可展开“查看默认提示词”查看；需要改写时填写自定义内容。模板中的时长和画幅会按项目或本镜设置展开，想生成30秒竖屏应选择30秒与9:16。所有N/X/Y由AI填写为实际编号和秒数，人物、场景、道具仍使用真实素材引用，自动生成的新片段最多9张参考图。

此版式用于每条分镜的完整视频提示词，程序外层仍保存JSON。新一轮分镜生成采用当前输出格式；已完成的分镜保持原样，单条点击“重新拆分分镜”即可按新格式重做。系统会把先前使用同一人物/场景的片段提供给AI作声音、机位和调色复用参考；跨段逐字一致属于模板指令，仍应在视频提交前查看生成文本。

## 修改图片和提示词

页面顶部“并发设置”分别控制图片和视频，默认各10条，可调1～50。可拖动滑块、点击加减或快捷数字，也可直接输入。保存后立即作用于排队任务；降低上限不会中断在途任务。所有项目、单张重做、恢复查询共用对应的并发池；服务商排队仍可能限制实际速度。配置保存在 `data/projects/concurrency.json`。

资产图片、编辑器中的图片、分镜参考图和确认窗口参考图均可点击放大，鼠标显示放大镜。放大预览周围透明可见底层页面，直接滚轮缩放，支持加减按钮、拖动、双击图片或“适应窗口”复位；点击图片外空白或Esc关闭预览，保留原编辑窗口。

“接口设置”的图片模型改为下拉选择，新增Image2（请求模型 `gpt-image-2`），继续使用Grsai中转站。切换模型只影响后续生图，不会自动重做已有图片。

资产卡片的“编辑”可以改名称、说明和生图提示词。“保存修改”只保存文字，“保存并重新生图”会调用生图服务重做这一张。上传按钮可用 PNG、JPEG、WebP 图片替换，单张不超过15MB。

分镜位于页面最后。点击“编辑提示词”调整动作、对白和运镜，在提示词输入 `@`，弹出可用图片候选，点击或用方向键与Enter选择。下方缩略图仅放大预览，不再自动插入引用。内部用稳定资产ID绑定图片，改名不会把引用绑到另一张图。

修改已制作过的整篇剧本或全局风格，再次拆解时会另建版本，保留原来的素材和视频。

## 跳过人工检查开关

在项目的“剧本与制作设置”中打开“跳过人工检查”，会保存到本项目，但不会立即执行生成。点击“开始全自动生成”后，依次拆解剧本、列资产清单、生成选中的图片、列出全部分镜，再自动加入视频队列。新提取的资产默认全选，已有清单按其所选资产继续。

此模式会产生图片与视频费用。开关默认关闭；开启后清单和全部分镜仍会列出。完整分镜未就绪、模型未上架、参数不兼容、引用缺失或上次提交结果未知时会停止。

关闭会停止后续自动衔接和未提交的视频，已提交任务继续查询，进行中的图片批次会完成。后台重启不自动启动新的完整流程，需再次点击开始；已有任务编号仍可继续查询，成品直接复用。

开启时，单镜或批量“开始生成”直接提交当前所选分镜；关闭后恢复最终确认弹窗。仅复制项目、保存开关或修改提示词不会启动生成。

## 调整时长与重新拆分分镜

每条分镜卡片直接提供时长下拉，也可在“编辑提示词”内修改。本镜从15改30秒后保存即生效，不会自动改动其他分镜。修改会让旧视频确认失效；提示词时间线需同步修改，或点击“重新拆分分镜”。

“重新拆分分镜”只调用DeepSeek重新处理当前条的动作与对白，可选择目标时长、补充修改要求，生成一条或多条替换当前条。其他分镜、素材图片和已有成片保留；失败原条不变。无论全自动开关状态如何，主动AI重拆完成后均不自动提交视频。

## 确认后开始生成视频

单镜点击“审阅并生成”，或勾选多镜后点击底部按钮。确认窗口显示本次参考图、模型、时长、画幅和实际提交提示词。

人工检查模式下，只有点击窗口内“开始生成N段视频”，才会上传参考素材并提交生成任务。重复点击处理中分镜不会再次提交。修改素材或提示词后，旧确认失效，需要重新检查。

视频可以后台排队，刷新网页或切换项目不会停止任务。完成后自动下载，可在页面播放和下载。重新生成会创建新任务，已有成片保留，生成费用按服务商规则计算。

## 查看进度和恢复

页面自动更新资产和视频状态，左下角“任务记录”查看步骤和错误。保持后台窗口运行；关闭后台后重新启动，已知任务编号的视频会继续查询。文字分析可继续拆解；图片与分镜可点击“生成所选”续接，已有远端图片任务优先查询，不重复提交。

显示“提交结果暂不明确”时，先核对服务商原任务，避免重复提交。已有任务但查询或下载失败时，先继续查询，不必重新生成。

## 提交视频后可以关机吗

已拿到服务端任务编号的任务在供应商侧处理，本机可关闭；仍在本机排队、上传或提交尚未返回编号的任务，请先等待。页面底部提示尚未提交数与已有编号数。第二天开机后还要启动工作台，已知编号的视频会自动查状态、下载；之前查询/下载失败但编号仍在的任务也会继续查询，不重复生成。

提交结果未知的任务不会自动重提，需核对供应商原任务。视频下载链接按供应商原文档有效24小时，请尽早启动接收；能否跨天保留和过期后补取以供应商为准，本机不能保证永久取回。

## 合成整集

所有当前版本的分镜视频完成后，“合成整集”会启用。多片段合成需要安装 FFmpeg，并让 `ffmpeg`、`ffprobe` 可在终端运行。它会统一片段媒体格式并保留原始视频；失败或时长异常不会伪报成功。

## 换电脑

便携包包含界面、后台、启动入口和说明，不包含 Key 或现有素材。新电脑安装 Node.js 后，在界面填写 Key 即可。

继续现有项目时，另行复制 `data/projects/`。先关闭旧电脑后台再迁移，避免两台电脑同时操作同一份文件。macOS 已完成实际验证；Windows 启动入口需要在目标电脑验证运行环境。

## 1.1.0 厂商、更新与分镜衔接

设置→接口配置，可为文字、图片和视频分别新增、保存、切换厂商方案。模型ID可自行填写。同一方案Key留空保留，新方案不会借用另一方案的Key。已有.env继续读取，界面保存的方案在 `data/projects/provider-settings.json`，不改写.env。支持协议、字段与限制见[公开发布与自动更新](公开发布与自动更新.md)。

设置→软件更新，仓库地址稍后填写。填好公开GitHub发布仓库后可自动检查、空闲安装并重启。只替换程序；Key、整个data、项目、图片视频、历史和自定义提示词保留，旧程序先备份。当前没有上传GitHub。

重拆前面的分镜后，后续条目显示“待对齐衔接”。点“一键AI对齐后续”，或逐条核对后点“已核对，确认衔接”。处理前拦截这些条目的视频提交。AI对齐全部成功后才替换分镜，旧版本和成片保留；请继续查看衔接结果。
